## Verwendung
Siehe [Einführung in die Release-Dateien](https://github.com/2dust/v2rayN/wiki/Release-files-introduction) und wählen Sie die benötigte Version zum Herunterladen aus.

### Windows
- Führen Sie `v2rayN.exe` aus

### Linux
- `chmod +x v2rayN` Führen Sie `./v2rayN` unter Benutzerberechtigungen aus
```
Debian 9+
Ubuntu 16.04+
Fedora 30+
```

### macOS
- `chmod +x v2rayN` Führen Sie `./v2rayN` unter Benutzerberechtigungen aus
```
macOS 11+
```

## Anforderungen  
- [Microsoft .NET 8.0 Desktop Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)
- [Unterstützte Cores](https://github.com/2dust/v2rayN/wiki/List-of-supported-cores)
