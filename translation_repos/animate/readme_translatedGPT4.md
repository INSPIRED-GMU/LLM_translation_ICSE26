## Installation

Installation mit npm:

```shell
npm install animate.css --save
```

Installation mit yarn:

```shell
yarn add animate.css
```

## Barrierefreiheit

Animate.css unterstützt die [`prefers-reduced-motion` Media Query](https://webkit.org/blog/7551/responsive-design-for-motion/), sodass Nutzer mit Bewegungsempfindlichkeit Animationen deaktivieren können. Auf unterstützten Plattformen (derzeit alle gängigen Browser und Betriebssysteme) können Nutzer in den Systemeinstellungen "Bewegungen reduzieren" auswählen, wodurch CSS-Übergänge automatisch deaktiviert werden, ohne dass weitere Maßnahmen erforderlich sind.
