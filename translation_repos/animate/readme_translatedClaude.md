## Installation

Installation mit npm:
```shell
npm install animate.css --save
```

Installation mit yarn:
```shell
yarn add animate.css
```

## Barrierefreiheit

Animate.css unterstützt die [`prefers-reduced-motion` Medienabfrage](https://webkit.org/blog/7551/responsive-design-for-motion/), damit Benutzer mit Bewegungsempfindlichkeit sich von Animationen ausschließen können. Auf unterstützten Plattformen (derzeit alle wichtigen Browser und Betriebssysteme) können Benutzer in ihren Betriebssystemeinstellungen "Bewegungen reduzieren" auswählen, wodurch CSS-Übergänge für sie ohne weiteren Aufwand deaktiviert werden.

## Mitwirken

Pull Requests sind hier der Weg zum Ziel. Wir haben nur zwei Regeln für das Einreichen eines Pull Requests: Halten Sie sich an die Namenskonvention (camelCase, kategorisiert [fades, bounces, etc.]) und lassen Sie uns eine Demo der eingereichten Animationen in einem [pen](https://codepen.io) sehen. Diese **letzte Regel ist wichtig**.
