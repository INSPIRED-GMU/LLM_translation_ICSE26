# Die Programmiersprache Go

Go ist eine Open-Source-Programmiersprache, die es einfach macht, einfache, zuverlässige und effiziente Software zu entwickeln.

![Gopher Bild](https://golang.org/doc/gopher/fiveyears.jpg)  
*Gopher-Bild von [Renee French][rf], lizenziert unter der [Creative Commons 4.0 Attribution Lizenz][cc4-by].*

Unser offizielles Git-Repository befindet sich unter https://go.googlesource.com/go.  
Es gibt einen Spiegel des Repositories unter https://github.com/golang/go.

Sofern nicht anders angegeben, werden die Go-Quellcodedateien unter der BSD-ähnlichen Lizenz verteilt, die in der Datei LICENSE zu finden ist.

### Download und Installation

#### Binäre Distributionen

Offizielle binäre Distributionen sind verfügbar unter https://go.dev/dl/.

Nach dem Herunterladen einer Binärversion besuche https://go.dev/doc/install für Installationsanweisungen.

#### Installation aus dem Quellcode

Falls keine Binärdistribution für deine Kombination aus Betriebssystem und Architektur verfügbar ist, besuche https://go.dev/doc/install/source für Anweisungen zur Installation aus dem Quellcode.

### Mitwirken

Go ist das Ergebnis der Arbeit von Tausenden von Mitwirkenden. Wir schätzen deine Unterstützung!

Um beizutragen, lies bitte die Beitragsrichtlinien unter https://go.dev/doc/contribute.

Beachte, dass das Go-Projekt den Issue-Tracker nur für Fehlermeldungen und Vorschläge verwendet.  
Eine Liste mit Orten, an denen du Fragen zur Go-Programmiersprache stellen kannst, findest du unter https://go.dev/wiki/Questions.
