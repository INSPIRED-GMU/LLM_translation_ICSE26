## Das Repository

Dieses Repository ("`Code - OSS`") ist der Ort, an dem wir (Microsoft) zusammen mit der Community das [Visual Studio Code](https://code.visualstudio.com)-Produkt entwickeln. Hier arbeiten wir nicht nur am Code und an Issues, sondern veröffentlichen auch unsere [Roadmap](https://github.com/microsoft/vscode/wiki/Roadmap), [monatlichen Iterationspläne](https://github.com/microsoft/vscode/wiki/Iteration-Plans) und unsere [Endgame-Pläne](https://github.com/microsoft/vscode/wiki/Running-the-Endgame). Der Quellcode steht allen unter der standardmäßigen [MIT-Lizenz](https://github.com/microsoft/vscode/blob/main/LICENSE.txt) zur Verfügung.

## Visual Studio Code

[Visual Studio Code](https://code.visualstudio.com) ist eine Distribution des `Code - OSS`-Repositories mit Microsoft-spezifischen Anpassungen, die unter einer traditionellen [Microsoft-Produktlizenz](https://code.visualstudio.com/License/) veröffentlicht werden.

Visual Studio Code kombiniert die Einfachheit eines Code-Editors mit den Funktionen, die Entwickler für ihren Kernprozess Editieren-Kompilieren-Debuggen benötigen. Es bietet umfassende Unterstützung für Codebearbeitung, Navigation und Verständnis sowie leichtgewichtiges Debugging, ein reichhaltiges Erweiterungsmodell und leichte Integration mit bestehenden Tools.

Visual Studio Code wird monatlich mit neuen Funktionen und Fehlerbehebungen aktualisiert. Du kannst es für Windows, macOS und Linux auf der [Website von Visual Studio Code](https://code.visualstudio.com/Download) herunterladen. Um täglich die neuesten Versionen zu erhalten, installiere den [Insiders-Build](https://code.visualstudio.com/insiders).

## Verwandte Projekte

Viele der Kernkomponenten und Erweiterungen von VS Code befinden sich in eigenen Repositories auf GitHub. Zum Beispiel sind das [Node Debug Adapter](https://github.com/microsoft/vscode-node-debug) und das [Mono Debug Adapter](https://github.com/microsoft/vscode-mono-debug) separate Repositories. Eine vollständige Liste findest du auf der Seite [Verwandte Projekte](https://github.com/microsoft/vscode/wiki/Related-Projects).

## Mitgelieferte Erweiterungen

VS Code enthält eine Reihe integrierter Erweiterungen, die sich im [extensions](extensions)-Ordner befinden, einschließlich Grammatiken und Snippets für viele Sprachen. Erweiterungen, die umfassende Sprachunterstützung (Codevervollständigung, Gehe zu Definition) bieten, tragen den Suffix `language-features`.

## Entwicklungscontainer

Dieses Repository enthält einen Visual Studio Code Dev Container / GitHub Codespaces Entwicklungscontainer.

* Für [Dev Containers](https://aka.ms/vscode-remote/download/containers) nutze den Befehl **Dev Containers: Clone Repository in Container Volume...**.

* Für Codespaces installiere die [GitHub Codespaces](https://marketplace.visualstudio.com/items?itemName=GitHub.codespaces)-Erweiterung.
