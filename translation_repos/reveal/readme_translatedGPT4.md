**reveal.js** ist ein Open-Source-HTML-Präsentationsframework. Es ermöglicht jedem mit einem Webbrowser, schöne Präsentationen kostenlos zu erstellen. Sieh dir die Live-Demo auf [revealjs.com](https://revealjs.com/) an.

Das Framework bietet eine leistungsstarke Funktionsvielfalt, darunter [verschachtelte Folien](https://revealjs.com/vertical-slides/), [Markdown-Unterstützung](https://revealjs.com/markdown/), [Auto-Animate](https://revealjs.com/auto-animate/), [PDF-Export](https://revealjs.com/pdf-export/), [Sprechernotizen](https://revealjs.com/speaker-view/), [LaTeX-Formelsatz](https://revealjs.com/math/), [syntaxhervorgehobenen Code](https://revealjs.com/code/) und eine [umfangreiche API](https://revealjs.com/api/).

---

Möchtest du eine reveal.js-Präsentation in einem grafischen Editor erstellen? Probiere [slides.com](https://slides.com) aus. Es wird von denselben Entwicklern wie reveal.js betrieben.
