Linux kernel
============

Es gibt mehrere Leitfäden für Kernel-Entwickler und -Benutzer. Diese Leitfäden können
in verschiedenen Formaten dargestellt werden, wie HTML und PDF. Bitte lesen Sie
zuerst Documentation/admin-guide/README.rst.

Um die Dokumentation zu erstellen, verwenden Sie ``make htmldocs`` oder
``make pdfdocs``. Die formatierte Dokumentation kann auch online gelesen werden unter:

    https://www.kernel.org/doc/html/latest/

Es gibt verschiedene Textdateien im Documentation/-Unterverzeichnis,
von denen mehrere die reStructuredText-Markup-Notation verwenden.

Bitte lesen Sie die Datei Documentation/process/changes.rst, da sie die
Anforderungen für das Erstellen und Ausführen des Kernels enthält sowie Informationen über
die Probleme, die durch ein Kernel-Upgrade entstehen können.
