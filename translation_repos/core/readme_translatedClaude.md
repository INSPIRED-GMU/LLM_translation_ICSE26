Home Assistant |Chat Status|
=================================================================================

Open-Source-Hausautomatisierung, die lokale Kontrolle und Privatsphäre an erste Stelle setzt. Unterstützt von einer weltweiten Community von Tüftlern und DIY-Enthusiasten. Perfekt für den Betrieb auf einem Raspberry Pi oder einem lokalen Server.

Besuchen Sie `home-assistant.io <https://home-assistant.io>`__ für eine `Demo <https://demo.home-assistant.io>`__, `Installationsanweisungen <https://home-assistant.io/getting-started/>`__, `Tutorials <https://home-assistant.io/getting-started/automation/>`__ und `Dokumentation <https://home-assistant.io/docs/>`__.

Vorgestellte Integrationen
---------------------

|screenshot-integrations|

Das System ist modular aufgebaut, sodass die Unterstützung für andere Geräte oder Aktionen einfach implementiert werden kann. Siehe auch den `Abschnitt zur Architektur <https://developers.home-assistant.io/docs/architecture_index/>`__ und den `Abschnitt zum Erstellen eigener Komponenten <https://developers.home-assistant.io/docs/creating_component_index/>`__.

Wenn Sie bei der Verwendung von Home Assistant oder während der Entwicklung einer Komponente auf Probleme stoßen, schauen Sie im `Home Assistant Hilfebereich <https://home-assistant.io/help/>`__ unserer Website nach weiterer Hilfe und Informationen.
