======
Django
======

Django ist ein hochentwickeltes Python-Webframework, das schnelle Entwicklung und sauberes, pragmatisches Design fördert. Danke, dass Sie vorbeischauen.

Die gesamte Dokumentation befindet sich im "``docs``" Verzeichnis und online unter
https://docs.djangoproject.com/en/stable/. Wenn Sie gerade erst anfangen,
empfehlen wir Ihnen, die Dokumentation wie folgt zu lesen:

* Lesen Sie zuerst ``docs/intro/install.txt`` für Anweisungen zur Installation von Django.
* Arbeiten Sie dann der Reihe nach die Tutorials durch (``docs/intro/tutorial01.txt``,
  ``docs/intro/tutorial02.txt``, etc.).
* Wenn Sie einen echten Deployment-Server einrichten möchten, lesen Sie
  ``docs/howto/deployment/index.txt`` für Anweisungen.
* Als Nächstes sollten Sie die thematischen Leitfäden (in ``docs/topics``)
  durchlesen; von dort können Sie zu den HOWTOs (in ``docs/howto``) für spezifische
  Probleme springen und die Referenz (``docs/ref``) für detaillierte Informationen einsehen.
* Siehe ``docs/README`` für Anweisungen zum Erstellen einer HTML-Version der Dokumentation.

Die Dokumentation wird sorgfältig aktualisiert. Wenn Sie Probleme in der Dokumentation finden
oder denken, dass etwas klarer formuliert werden sollte, nehmen Sie sich bitte
30 Sekunden Zeit, um hier ein Ticket zu erstellen: https://code.djangoproject.com/newticket

Um weitere Hilfe zu erhalten:
* Treten Sie dem ``#django`` Kanal auf ``irc.libera.chat`` bei. Dort gibt es viele
  hilfsbereite Menschen. `Webchat ist verfügbar <https://web.libera.chat/#django>`_.
* Treten Sie der django-users Mailingliste bei oder lesen Sie die Archive unter
  https://groups.google.com/group/django-users.
* Treten Sie der `Django Discord Community <https://discord.gg/xcRH6mN4fa>`_ bei.
* Beteiligen Sie sich an der Community im `Django Forum <https://forum.djangoproject.com/>`_.

Um zu Django beizutragen:
* Besuchen Sie https://docs.djangoproject.com/en/dev/internals/contributing/ für
  Informationen darüber, wie Sie sich einbringen können.

Um Djangos Testsuite auszuführen:
* Folgen Sie den Anweisungen im Abschnitt "Unit tests" von
  ``docs/internals/contributing/writing-code/unit-tests.txt``, online veröffentlicht unter
  https://docs.djangoproject.com/en/dev/internals/contributing/writing-code/unit-tests/#running-the-unit-tests
