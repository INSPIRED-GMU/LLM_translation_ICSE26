## Entwicklungseinrichtung

### Voraussetzungen

- Installieren Sie [Node.js], das den [Node Package Manager][npm] enthält

### Projekt einrichten

Installieren Sie die Angular CLI global:

```
npm install -g @angular/cli
```

Erstellen Sie einen Workspace:

```
ng new [PROJEKTNAME]
```

Starten Sie die Anwendung:

```
cd [PROJEKTNAME]
ng serve
```

Angular ist plattformübergreifend, schnell, skalierbar, verfügt über unglaubliche Tools und wird von Millionen geliebt.
