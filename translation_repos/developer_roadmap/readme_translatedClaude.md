## Entwicklung

Klonen Sie das Repository, installieren Sie die Abhängigkeiten und starten Sie die Anwendung

```bash
git clone git@github.com:kamranahmedse/developer-roadmap.git
cd developer-roadmap
npm install
npm run dev
```

Hinweis: Verwenden Sie den `depth`-Parameter, um die Klongröße zu reduzieren und das Klonen zu beschleunigen.

```sh
git clone --depth=1 https://github.com/kamranahmedse/developer-roadmap.git
```
