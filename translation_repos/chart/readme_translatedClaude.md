## Mitwirken
Anweisungen zum Erstellen und Testen von Chart.js finden Sie in [der Dokumentation](https://www.chartjs.org/docs/master/developers/contributing.html#building-and-testing). Bevor Sie ein Problem melden oder einen Pull-Request erstellen, nehmen Sie sich bitte einen Moment Zeit, um die [Richtlinien für Mitwirkende](https://www.chartjs.org/docs/master/developers/contributing) durchzulesen. Für Support stellen Sie bitte Fragen auf [Stack Overflow](https://stackoverflow.com/questions/tagged/chart.js) mit dem Tag `chart.js`.
